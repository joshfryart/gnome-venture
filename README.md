# Gnome Venture

Cosy garden browser game (plain PHP 8.1+, MySQL, vanilla JS). Live: gnomeventure.ca.

Private repo. Read `claude/handoff.md` first, then `claude/todo.md`.

## Layout
- `game/` web root (pages, includes, admin, assets, data)
- `tests/` test suites and build scripts
- `claude/` project docs (handoff, todo, changelog, plans)

## Not in git (see .gitignore)
config.php, runtime data/cache, player uploads, backups, AI tool folders, zips.
