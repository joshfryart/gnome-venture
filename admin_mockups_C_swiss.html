Gnome Venture admin: control room

Direction C. Near-black blue ground for a phone at night after an update; flat fields, no texture, one signal colour (tangerine) that means "this needs you" or "this is selected". Failure is a filled square, warning an outlined triangle, ok a ring, and each carries its word, so colour is never the only cue.

Type is Archivo, tight scale (12 / 14 / 16 / 22 / 40 / 56). Tables are the hero. The frames are live: Ctrl-K or the search field opens the palette, rows select, cells edit, the settings fold opens.

1. Dashboard

Triage queue first (failed step, error log, messages), then system status, then counts as a plain table.

2. Items data editor

Filter, sticky header, inline cells (dashed = editable, "Edited" marks unsaved, one invalid price), bulk bar, row actions, pager. Phone folds each row to two lines instead of scrolling sideways.

3. Game settings

Search, groups, an Advanced fold, switches that say On or Off, an error with its recovery, and a sticky save bar that counts changes.
