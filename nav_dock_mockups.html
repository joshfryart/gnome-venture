Gnome Venture dock

Proposed landscape navigation. Four big buttons open a sub-menu slip. Two page actions and the status plate sit in the flat middle. The top bar is gone. Try it: tap a big button, tap a tile, change the page, flip the switches.

How it works

Four menus, same groups as today

You, Hobbies, Out and about, Together. Left thumb: You and Hobbies. Right thumb: Out and about and Together. Same tiles the current menu sheet already builds, so badges and unlock rules carry over.

Two taps to anywhere

Big button, then tile. The tapped big button turns gold and lifts. The tile for the page you are on gets a gold fill and a "you are here" tag. Close with the same button, a tap on the page, Esc, or Back.

Where am I, slip closed

The big button of the current section keeps a small gold bar. Pages that are not a tile (a door, a profile, a mini-game) still light their parent section.

Left action and right action

Right is the one thing this page is for. Left is the helper next to it. Both are chosen by the page, with a default of Back and Hovel. Counts show as a red badge. A greyed action says why in a tiny chip.

Status plate

Energy, level, game time and where your pals are. Tap it for the rest: health, Petals, season and weather, festival, ready pots and jars, stat points, theme switch.

Play mode

Rounds, fights and games need the whole screen. The arc drops to a thin rail with Quit and the main verb. Menus are locked until the round ends.

Every page, one row each

All 0 files in game/*.php. Pill "new" means no matching handler was seen in the page, so it needs a small endpoint or a promoted control. Everything else is a button the page already has, lifted into the dock. I read page names, tabs and do= handler names, not every line of every page, so check each row when you build it. Roll-out

1. Behind a flag

New setting nav_dock, admin preview first, same pattern as gnav_on. Landscape only. Portrait keeps today's header, strip and bottom bar.

  • nav_sheet() feeds the slips (same groups, badges, unlocks)
  • status_strip() feeds the plate
  • new dock_actions() registry

2. Pages declare actions

Each page sets $GLOBALS['gv_dock'] with left, right and mode. AJAX pages return it in the swapped fragment so site.js updates the buttons in place.

  • start with Garden, Tasks, World, Satchel
  • then play-mode pages
  • default Back and Hovel for the rest

3. Retire the old chrome

Remove header, status strip, bottom bar, side menu and right rail for flagged players. Move theme, log out, feedback and staff tools to You, Account. Add "turn your phone" hint in portrait.

4. Lock landscape

When portrait usage is low, set "orientation": "landscape" in manifest.json for installed play. Keep portrait fallback for login, register and account in browsers.
