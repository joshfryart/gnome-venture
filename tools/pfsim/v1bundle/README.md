# v1bundle: sims for the v1 board bundle (board size, use-up, ground, events, aim, Teamwork)

Scratch quality. Sim only: nothing here is loaded by the game. Results are in `claude/design-board-strategy.md` ("Sim results 3 (full v1 bundle)"). The scripts as used for sim 1 and sim 2 are in git history (commits "design: v1 bundle sim results" and "design: v1 bundle sim 2"); the rules changed since, so their numbers do not reproduce from this version.

- `mkengine.py` builds `pfboard_v1.php`, a patched copy of `game/includes/pfboard.php` with the v1 rules behind switches: board size by creature size, ground cells (sunny, bramble, mud) for both sides, an environment turn with forecast events that move ground (sunbeam, bramble creep, puddle), push a piece (gust) or burst (thorn burst, half strength on creatures), chains of 3+ use up the fired pieces (both sides), the creature's aim (shown and committed, no fumble), Teamwork (2 sources +30%, 3 sources +60%). Re-run it after the real engine changes: `python3 tools/pfsim/v1bundle/mkengine.py`.
- Switches: env `V1` holds JSON over `V1_DEFAULTS` (top of `pfboard_v1.php`). A value may be a map by creature size. The recommended numbers of sim 3 are the `F=` line in `side3.sh`. Today's rules: `V1='{"dims":[7,5],"ground":0,"events":0,"limit":0,"aim":0,"team":1,"team2":1,"foe":1}'`.
- `php run.php BOT OFFSETS [SHARD/N] [MULT]` plays fights and prints one JSON line per fight. Bots: random, chain (always the longest chain), greedy (best own-chain numbers), look (best state after the shown aim and the announced environment turn), smart (two turns ahead, with set-aside), never3 and smartn3 (look and smart that avoid using pieces up). `look-g`, `look-e`, `look-ge`, `smart-g`, `smart-e`, `smart-ge`: the same bot, but it ignores ground (g) and / or events (e) when it chooses. OFFSETS = gnome level minus creature level (`0,-4,-8`). MULT 1 = 200+ fights per size and level.
- look and smart fights also record, each turn, whether their best move changes when ground / events are hidden (`bm_*` keys: look by one-turn reading, smart by its two-turn score; `METRIC=0` turns it off, `METRIC=1` makes smart use the one-turn measure).
- Env `SRC`: sources on the gnome's pieces for Teamwork. Default "mixed" = 1 pal, 2 tool, 2 crop, the rest knacks; `SRC=built` = 2 pal, 4 tool, 4 crop; `SRC=thirds` = every piece; `SRC=none`.
- `bash par.sh LABEL 'V1-JSON' "bots" OFFSETS [MULT]` runs 4 shards per bot in parallel into `out/LABEL.jsonl` (`out/` is not committed).
- `php agg.php out/LABEL.jsonl` prints the main markdown table (bot x size x level: win %, health lost %, turns). `php agg3.php out/LABEL.jsonl [--sizes] [--pieces] [--bots=a,b] [--d=0]` prints one line per bot and level with everything else (columns are listed at the top of the file).
- `bash sweep3.sh "bots" OFFSETS MULT label=json ...` compares rule variants. `bash side3.sh > out/side3.txt` re-runs the main table and every side experiment of sim 3 (about 45 minutes on 4 cores).

Numbers move about 4 points run to run at 200 fights per cell.
