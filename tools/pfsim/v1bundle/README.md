# v1bundle: sims for the v1 board bundle (use-up, ground, events, aim, Teamwork)

Scratch quality. Sim only: nothing here is loaded by the game. Results are in `claude/design-board-strategy.md` ("Sim results (v1 bundle, spend-on-chain)" and "Sim results 2 (bite settings)").

- `mkengine.py` builds `pfboard_v1.php`, a patched copy of `game/includes/pfboard.php` with the v1 rules behind switches: ground cells (sunny, bramble, mud) for both sides, an environment turn with forecast events (rain, wind, thorn burst), chains of 3+ use up the fired pieces (both sides), the creature's aim (shown and committed, no fumble), Teamwork. Re-run it after the real engine changes: `python3 tools/pfsim/v1bundle/mkengine.py`.
- Switches: env `V1` holds JSON over `V1_DEFAULTS` (top of `pfboard_v1.php`). The defaults are Josh's start settings (sunny x2, bramble 10%, events 10% per piece, Teamwork +60%, creature x1.35, 5 ground cells 2-3 steps out, 1 event a round). The recommended numbers of sim 2: `V1='{"nsun":3,"nbr":3,"nmud":1,"gmin":1,"gmax":2,"nev":2,"foe":1.3}'`. Today's rules: `V1='{"ground":0,"events":0,"limit":0,"aim":0,"team":1,"foe":1}'`.
- `php run.php BOT OFFSETS [SHARD/N] [MULT]` plays fights and prints one JSON line per fight. Bots: random, chain (always the longest chain), greedy (best own-chain numbers), look (best state after the shown aim and the announced environment turn), smart (two turns ahead, with set-aside), never3 and smartn3 (look and smart that avoid using pieces up). `look-g`, `look-e`, `look-ge`, `smart-ge`: the same bot, but it ignores ground (g) and / or events (e) when it chooses. OFFSETS = gnome level minus creature level (`0,-4,-8`). MULT 1 = 200+ fights per size and level.
- look and smart fights also record, each turn, whether the best one-turn move changes when ground / events are ignored (`bm_*` keys; `METRIC=0` turns it off).
- `bash par.sh LABEL 'V1-JSON' "bots" OFFSETS [MULT]` runs 4 shards per bot in parallel into `out/LABEL.jsonl` (`out/` is not committed).
- `php agg.php out/LABEL.jsonl [--detail] [--bite]` prints the markdown tables (bot x size x level: win %, health lost %, turns; `--detail` adds chain and board numbers; `--bite` adds ground, events, Teamwork, best-move changes and piece shares).
- `bash sweep.sh "bots" OFFSETS MULT label=json ...` compares rule variants. `bash side.sh > out/side2.txt` re-runs the side experiments of sim 2 (about 30 minutes on 4 cores).
- Env `SRC=thirds` gives every piece a source (pal, tool, crop in turn; a deck built for Teamwork), `SRC=pairs` at most 4 of each; default is 2 pal, 2 tool, 2 crop pieces per deck. Env `HOARD=0.05` makes look and smart value their own pieces on the board.

The main table of sim 2: `bash par.sh final2 '{"nsun":3,"nbr":3,"nmud":1,"gmin":1,"gmax":2,"nev":2,"foe":1.3}' "random chain greedy never3 look-ge look smartn3 smart-ge smart" 0,-4,-8 1 && php agg.php out/final2.jsonl --detail --bite` (about 12 minutes).
Numbers move about 4 points run to run at 200 fights per cell.
