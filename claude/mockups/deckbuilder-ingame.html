What is real and what is drawn by hand
  • Real code or art: style.css tokens and shell classes (banner, status strip, box, btn, tabs, chip, bottom bar), pfight.css, jigsaw piece art, the fight board and hand (a captured frame of the game's own renderer and engine), pixel icons, creature sprites.
  • Drawn for this mockup: the Gear, rank, class and layer layouts, the swap strip, the lean bar. Rank is a chip because the rim-trim art is not made yet.
