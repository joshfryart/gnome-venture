# ================= THINGS TO CHECK BEFORE THIS GOES IN (found, not fixed) =================
# 1. BALANCE (the one to sim). Stats come from size + level in import_creatures_txt (includes/adventure_data.php, about line 422):
#      hp = (5 + 3*level) * size mult (0.8 / 1.1 / 1.6 / 2.4) · attack = 1 + level/3 + (0/0/2/2) · defence = 9 + level/3 + (0/1/2/3)
#      damage = d4/d6/d8/d10 + level/4 · xp = level * 6 * size mult. The formula is linear with no cap, so it does work above 40:
#      large Lv 45 = 224 hp, attack 18, defence 26, d8+11 · boss Lv 50 = 372 hp, attack 19, defence 28, d10+12 · boss Lv 55 = 408 hp, attack 21, defence 30, d10+13.
#    But the d20 maths drifts (includes/adventure.php gnome_combat, includes/combat_math.php):
#      gnome attack = 2 + level/2 + stat, against defence growing at level/3: at Lv 55 a gnome has +29 before stats against defence 28-30, so it hits on almost any roll.
#      gnome armour = 10 + nimble + level/4, against creature attack growing at level/3: at Lv 55 armour 23 + nimble against attack +21, so the creature also hits on almost any roll.
#    So from about Lv 45 the dice stop mattering and fights are a race of health against damage. Nothing above Lv 40 has been simulated; run a sim at 45 and 55 before shipping.
#    Fleeing: the roll needs d20 + nimble >= 8 + level/3, which is 26 against a Lv 55 foe: impossible without nimble 6 or more.
# 2. Fixed routes are clamped to Lv 40: route_danger() in includes/adventure.php lines 179-180 does min(40, ...) on min_level and max_level.
#    pick_creature takes ordinary creatures of level-6 .. level+2, so on a fixed route nothing above Lv 42 would ever be met until that clamp is raised.
# 3. Lair bosses do not come from creatures.txt. ensure_lair_bosses() (includes/landmarks.php about line 558) makes a creature `boss-<location slug>` per lair,
#    named from the "of the X" part of the lair name, at the level of the lair's side route, with the drops copied from the LOWEST-level boss of creatures.txt
#    that fits the lair's landscape. Imported as rows, the seven lair lines would have become
#    active roaming bosses with the same names as the (inactive) generated guardians: duplicates. Pass 4: they are now `#L|` overrides. Needed code: a lair
#    override step (data file or boot step) that sets name, level, drops and description on the `boss-<slug>` rows, for new and existing worlds.
#    Generated names differ for Snowcrown Peak AND Dragonlizard Den (neither has "of the" in its name).
# 4. Lair levels are set in LAIR_LEVEL_1115 (includes/roads.php line 9) at the old region levels (8 to 37), and REGION_LEVELS (includes/progression.php line 10)
#    still has the old values (MENA 17 ... OC 35). Both need the new bands: REGION_LEVELS NA 1, CA/NWE 15, CB/SA/SE/EE 25, MENA/CSA/WCA/ESA 35, EA/SEA/OC 45;
#    lairs at band top (Owl 15; Smokecap, Frost Toad 25; Hurricane Crab, Condor's Crag, Cinder Wyrm, Grey Wolf King 35; the seven above 45/55),
#    with a boot step for existing worlds (as medium_lair_levels_1115 did). The clamp min(40, ...) in route_danger must rise to at least 57.
# 5. Roaming bosses: any boss of the landscape with level <= walk level + 8 can turn up (6% roll) and lower ones are scaled up, so the Lv 44-45 bosses start
#    appearing on Lv 36-37 walks and the old Lv 26-32 bosses still roam at Lv 55. That is how it works today; say if the new ones should be region-bound in pf_creatures.txt.
# 6. pf_creatures.txt already has named variants at Lv 38-40 placed by the OLD region levels (Ratel Pair, Emu Mob, Lava Beetle, Gorse Beast, Old Brock, Conger Brute,
#    Elder Tiger, Mangrove Crab Emperor, Ibex Patriarch, Musk Ox, Reef Eel Tyrant, Alpha Dingo, Kraken Spawn). Their regions and levels will need a pass when the bands move.
#    Each creature here also needs its pf_creatures.txt row (regions, ability, deck, petals, art) to be region-bound and to fight on the board.
