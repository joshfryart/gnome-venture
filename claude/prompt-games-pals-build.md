## Build (behind a new flag `gnav_tree`, default 0; flag off = today's pages exactly)
1. **Treehouse picture (10a).** `games.php` becomes one big cut-away tree with rooms as hotspots. Room grouping lives in data: `includes/data/treehouse_rooms.php` (room id, name, game keys, slot positions), so a new game is one line. Rooms from the plan: Parlour (memory, letters), Loft (race, spit), Cellar (marrow, carve, worms); Puzzle Room (`puzzles.php`, gated by `puzzles_open`), Cat Fish nook (`catfish.php`, `catfish_open()`), Contest Hall / trophy shelf (`games.php?tab=contests`) with "This week's high scores" (`game_top()`), Pal Book bookshelf (`puzzlepals.php`), Yard door (to Pal Yard). Locked rooms: closed shutters + the unlock text. Text twin: today's tile grid at `?view=list`, remembered per gnome.
2. **Puzzle Pals live in the tree (10b).** Each found pal gets a stable perch (slot = index in found order, append-only) from a `pals` slot list in the layout JSON (about 24 perches: branches, sills, swing, rug, hearth, shelf). Sprite lookup: `assets/img/pals/<key>.png`, then the existing sticker, then piece crop, then silhouette. Arrival: first view after finding a pal plays a small sparkle (`found_at > last_seen`, last_seen stored per gnome in a small table `hub_seen`). Milestone dressing at 5/10/20/40 pals (rug, string lights, telescope; data driven, layers optional). Party pal sits by the door/shoulder (not duplicated); a pal on a job shows an empty perch with an "away" tag and return time. Tap a pal opens a popover: name, rarity, level, times found, Take along / Send home (existing POSTs), Send on a job. Edge cases: 0 pals (empty tree + hint "Solve jigsaws to find pals"); 150+ pals (extras live in the Pal Yard; tree shows the first N and "+12 in the yard"); `ppal_open()` off or guest (pal parts hidden, games still shown); removed or renamed pal keys are skipped, never fatal; one `ppal_found_map` call per page.

Tap a site opens a popover with the existing job form for that kind (pal radio list, options, Send). Pals out are drawn at their site with a progress ring; done jobs show a Collect bubble; idle pals stand on the yard's stand slots. One popover at a time; the Ledger popover keeps the existing countdown JS (`assets/paljobs.js`). Reuse `pj_*` and the existing POSTs unchanged; `pj_max_away`, daily caps and the level gate unchanged and shown in the popover. Edge cases: more jobs than site slots (extras listed in the Ledger), a job finishing while open, low-HP pal (sick-bay badge), pal both in party and on a job (blocked by `pj_can_send`, say why), no pals at level (empty yard + hint).
