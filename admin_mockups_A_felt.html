Gnome Venture admin, direction A: Stitched Toy, grown up

Same felt chrome, gold stitch, cream panels and hard corners as the game. What changes: one section rail instead of a 30-page list, a command search that is always one tap away, alerts as a triage strip, drawn icons, and a calmer data editor.

1. Dashboard

Triage first (what needs me today), then the daily inbox, pinned and recent pages, system state. The old menu of nine accordions becomes a quiet index at the bottom, and the rail plus search replace it for navigation.

3. Game settings form

Settings search filters live (try "energy" or "trek"). Common fields first, risky switches grouped, rarely touched values folded away. Changed fields are marked in words, and the save bar sticks to the bottom with the count. The frame scrolls on its own so the bar can stick.

What changed from today

  • One place per job. Update, settings, backups and logs sit in one rail section, so "Update the game" is always two taps from anywhere.
  • Status has a word and a shape. Error is an octagon, warning a triangle, ok a tick box, off a dashed box. Colour only backs it up.
  • Icons are drawn. One 2 px square-cap stroke set replaces emoji, so they look the same on every phone.
  • Pixel language kept. Radius 0, stepped shadows, dashed gold thread, moss primary, no pure black.
  • Moving parts. Switches step in 3 frames; all motion stops under reduced motion.
