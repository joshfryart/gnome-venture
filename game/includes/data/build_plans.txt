# Build plans (v2.0.76): how each ruined haven, wonder or delve is made safe. Four stages per place, handed in one at a time.
# A place with no plan here uses the old four stages (stone + Petals, timber + rope, meals, fine finds + Petals).
# P|Landmark name|stage 1-4|verb|Stage title|needs|a line of story for the card
# Names must match landmarks.txt exactly. Text must not contain the | character. Use ’ (curly) for apostrophes.
# verbs (the icon and the button; the needs do the work):
#   haul    hand in building materials          gather  hand in things found on the road or in the wild
#   feed    hand in cooked food for the crew     light   hand in what lights the place (wax, lanterns)
#   clear   work here on different days (spends energy; one day counts once)
# needs, comma list:  item:slug:qty   coins:N   meal:N (home-cooked meals or feasts)   fine:N (uncommon or rare finds)
#   days:N:E   clear only: N different days, E energy each. A clear stage has only this need (it finishes by itself on the last day).
# Costs scale with the region's level (rule in tools/scale_build_plans.py; this file is GENERATED from claude/build-plans-base.txt, edit the base and re-run):
#   factor = 1 + (L - 1) / 40, L = region level (Maplewold 1 ... Oceania 35); item / meal / fine counts x factor (rounded, min 1; tools handed in are not scaled);
#   coins: + 5 per level above 1; clear stages (days:N:E) are never changed. Example: 4 Rope + 250 Petals at level 1 is 7 Rope + 420 Petals at level 35.
