# slug|Name|kind|stat|power|items
#   slug   the component's key (used in teas.txt, in the form and in the journal). Never rename one that is live.
#   kind   leaf, herb, flower (may be the BASE: it steeps) · spice, fruit (extras only) · sweet (one a cup) · milk (one a cup)
#   stat   grit, nimble, hardiness, lore, sense, charm, luck. Empty for sweet and milk (they lift the cup's own stats).
#   power  steep points: 2 = true leaves, roots and spices; 1 = other herbs, flowers and fruit; 0 = sweet and milk.
#   items  item slugs that count as this ingredient, comma separated, tried in this order (empty = the same slug).
#          A "?" after a slug = the item is made on first use by the game (dried flowers), so it may not exist yet.
