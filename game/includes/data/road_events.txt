# Road and wilds scenes (v1.9.4). Little choice cards ("events") and strange sights. Edit freely; keep one row per line.
#
# E|id|cond|lands|region|where|icon|scene text            starts a choice card; the O rows under it are its options
# O|label|stat|dc|win effect|win text|lose effect|lose text   stat blank = no roll (then the win effect always happens)
# S|id|cond|lands|region|where|icon|text|effect             a strange sight (wilds only: a one-line find, no choice)
#
# cond:   - = always. Rest-stop syntax: dp=dawn,day,dusk,night  se=spring,summer,autumn,winter  we=sun,cloud,rain,storm,frost,heat,wind,fog,snow
#         (join with /). A plain cond makes the scene 3x likelier when it holds; "!" in front = it ONLY happens then.
# lands:  comma list of forest,grassland,coast,mountain,desert,rainforest,wetland,tundra,island, or any.
# region: a region code (NA NWE EA ...) or any. A scene for the region you are walking through is likelier than a generic one.
# where:  road (walks between stops), wild (exploring off the path) or both.
# stat:   grit nimble hardiness lore sense charm luck.   dc: about 10 (easy) to 13 (hard); a little harder further off the path.
# effects (same language as random events): xp:N  coins:A-B  {c} = Petals sized for the depth  item:slug:N  rand:forage|uncommon|food
#         energy:N  buff:stat:amount:minutes  heal:N  hp:-N (never knocks you out)  pay:N (checked first: no free money)  landmark (wilds only)
#         Join with +. Add @N (percent) to make a part happen only sometimes: item:garden-honey:1@15
#         On a road, every item or rand part is capped at 20% and only common/uncommon finds are given, whatever it says here.
# Text must not contain the | character. Use ’ (curly) for apostrophes.
#
