Gnome Venture admin, set as a gardener's ledger

Direction B. Warm paper, ink and sepia, one green and one vermilion. Frames below are live components at the widths they ship at: phone 412px and desktop 1100px. The layout of each frame is container-driven, so each one adapts to its own width.

1. Dashboard, read as a day's entry

What needs you comes first as ledger lines, each with a stamp that carries a word and a mark as well as a colour. Then the count, then the log. The contents index (dotted leaders, counts) replaces the section-of-choice-rows menu.

Phone, 412px

Desktop, 1100px

2. Items, the data editor list

A table first. Filter above it, sortable headers, one row per item, three row actions, a pager that says where you are. On the phone the same rows set as a list with full-width action buttons. The third row of the desktop table shows hover, and the Edit button on that row shows keyboard focus.

Phone, 412px

Desktop, 1100px (type in the filter to try it; "zzz" gives the empty result)

3. Game settings, the form

Search and the everyday/advanced switch on top, jump chips, settings grouped under sub-headings by their feature prefix, the advanced fold closed by default, and a save bar that stays put and says what is unsaved. One field is in error. Scroll inside the frame to see the bar stick.

Phone, 412px (scrolls)

Contents page, phone

4. States

Empty, error, disabled, loading and focus, each with words as well as colour. Motion is limited to a short colour fade, and a spinner that holds still when reduced motion is asked for.
