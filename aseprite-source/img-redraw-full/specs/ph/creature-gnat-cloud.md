# ph/creature-gnat-cloud
- canvas: 64x64, mode sticker, 1x.
- subject: A swirling cloud of eight tiny gnats, each a small round dark body with a pair of pale wings, scattered in a loose ring; buzzing and annoying.
- must-read-at-16px: scatter of small dark dots each topped with pale wings, in a loose cluster.
- distinct: Not one body but eight separate bugs in a loose cloud with gaps between them; each gnat has a two-lobe wing pair.
- parts (back to front):
  1. wing pairs: eight pairs of 7x3 ovals, pale #e6f1ec (cream-safe), above each body, centred (16,23) (31,16) (42,26) (22,37) (36,41) (13,46) (46,46) (27,28)
  2. bodies: eight ovals 5x4 at (19,25) (34,18) (45,29) (25,40) (39,43) (16,49) (50,49) (30,31), #8f7060 (warm grey-brown)
  3. eye dots: 3x3 #2a1a10 on each body, offset slightly left
- joins: none.
- face: each gnat has one tiny 3x3 eye with a glint; no 5x5 eyes (too small).
- notes: bodies at least 3 px wide, spread so the halo merges the cloud into one sticker; irregular positions, no grid. Wings flat pale, no shade.
