## Flood Boots: why they still only show rows ~61-70, and the real fix (game code NOT changed)
Stack (gnome25.php, `GNOME25_ORDER` + `GNOME25_WEAR_AFTER`): front = cape, pack, shadow, outline, boots, **wboots**, tunic, scarf, skin, gloves, beard, face, hat, brim, trim. The tunic's legs reach row 63-64, so anything in front-wboots above that is covered.
Fix (one line, `game/includes/gnome25.php` line 15): in `GNOME25_WEAR_AFTER['front']` change `'wboots' => 'boots'` to `'wboots' => 'tunic'`. The boots then draw over the tunic's legs from the rim at row 60, i.e. ~11 rows of boot instead of ~7 (wellies over trousers). This new strip already contains that rim and shaft, so no redraw is needed for it; checked in all 8 frames (lifted feet rise to row 57 over the hem, which reads as a knee lift). Two follow-ups if you make the change: (1) in `front-wboots.lua` drop the "hem shadow" line (it darkens the row under the tunic, which is right for the current stack only), re-run; (2) back view needs the same (`'back' => [...
