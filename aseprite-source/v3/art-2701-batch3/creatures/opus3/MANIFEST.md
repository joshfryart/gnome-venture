# creatures/opus3: Opus richness pass, 9 creature pictures

Built on `../opus2/`. Each `<name>.png` has the same canvas size and file name as opus2 and the game picture. `<name>.before.png` is the current game picture (copied unchanged from opus2). Nothing under `game/` was touched.
Every `.lua` runs `HP.assertClean` (no semi-transparent pixels, no pure black or white). Locked eyes come only from `c:eyeLocked` / `c:eyeSmall`.
Run: `/tmp/claude-0/ase/squashfs-root/AppRun -b --script-param out=<dir>/ --script <name>.lua`. Each script needs `v3/lib/hp.lua`, `v3/lib/hpx.lua` and `_rich.lua` (this folder).

`_rich.lua` holds the shared tools: hue-shifted 6-tone ramps (`Q.ramp`, `Q.six` expands a 4-tone design ramp), per-pixel upper-left light quantised to the ramp with a texture hook (`Q.body`), and a bounce line on the lower edge.

All nine now have 6-tone hue-shifted ramps (cool darks, warm lights), one light from the upper-left with one shade side on the lower-right, a lit rim and a bounce line.

## Remaining weaknesses
- **mini-basalt-borer:** the plates are richer but the whole body reads a little darker and greyer than the game picture. The vesicle pits can look like random dots at 400%.
- **mini-blight-mother:** the wing-scale rows make the two forewings busy at 400%. They read fine at 100%.
- **mini-dew-leech:** the drop is still only 4x5 px, because the canvas is 23 px tall.
- **folk-moth-1:** the body fur, ruff and wings are all pale mint and cream, so the lower half has low contrast at 50%. The nibbled hole is small and can read as a stain.
- **folk-tortoise-1:** the neck is shorter but still wide. The snail is 8x5 px and reads only at 100% and above.
- **folk-butterfly-1:** the ladybird is 3x3 px, so it is a closer-look detail only.
- **Fight rigs and walk strips** (`game/assets/img/fight/rig-*`, `folk/sprite/*`) still do not match these stills (same as opus2).
- **Off-palette colours:** off-palette hand-set ramps are used throughout, which is allowed. `HP.report` lists them.
