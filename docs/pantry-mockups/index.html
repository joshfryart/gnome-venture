Pantry: 5 low-fi directions

Current page is ~15,000 px tall on a phone (156 recipe cards, each with large ingredient frames). Each option below shows desktop (1440) then mobile (390). Same content in all five; low-fi, game palette. Real page unchanged until you pick.

A · Shelf + dense rowsSafest

Jars become a horizontal shelf with progress bars. Recipes collapse to one-line rows with have/need chips. Filters are chips, not selects. Cuts the long scroll the most for the least change.

B · LedgerDensest

Jars and recipes as compact tables. Highest density, easiest to scan and compare times. Least game-feel.

C · Timeline groupsShortest page

Recipes grouped by wait (1 / 2 / 3 / 5 / 7 / 14 days) in accordions, first open. Sticky jar strip. Page is short because most is folded.

D · Master–detailKeeps ingredient art

Compact recipe list; one detail panel shows the big ingredient frames for the selected recipe only. Mobile: sticky bottom sheet.

E · Tile grid + drawerMost visual

Search plus icon tiles with ready/missing dots. Tap a tile to open make-actions in a drawer (sticky on mobile). Most visual, fewest words.
