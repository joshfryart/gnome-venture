Pantry: D and two iterations

Desktop (1440) then mobile (390) for each. Low-fi, same content. Real page unchanged.

D · Original pick

Master–detail. Compact list, one detail panel, sticky bottom sheet on mobile.

D2 · Find, then make

Adds search and kind chips (Jam / Chutney / Pickle…). Jars shrink to one chip row. Detail shows ready date in a free jar plus have/need on each ingredient frame. Mobile: sticky sheet with the same actions.

D3 · Jars rail

Desktop gets three columns: jars rail (with Collect), recipe list, detail. Mobile: jars fold to one "5/7 · 1 ready" bar, and the selected recipe opens inline in the list, with a sticky Make bar. No separate sheet to scroll to.
